# Очистка и предобработка данных по недвижимости (SQL)

В данном проекте я провёл полный цикл очистки и подготовки «грязных» исторических данных о продажах жилья для последующего анализа. Все этапы трансформации выполнены с помощью написания SQL-запросов.

### Основные задачи и реализованные решения:
* Заполнение пропущенных данных: Нашёл пропущенные адреса объектов и автоматически заполнил их, связав таблицу саму с собой (Self Join) по совпадающим идентификаторам участков.
* Парсинг и разделение строк: Разбил комплексное текстовое поле с адресом на отдельные атомарные столбцы (Улица, Город) с помощью строковых функций.
* Очистка от дубликатов: Используя оконную функцию ROW_NUMBER, вычислил и полностью удалил повторяющиеся идентичные записи, чтобы избежать искажения статистики.
* Стандартизация и форматирование: Привёл даты из текстового формата к корректному типу DATE, исправил артефакты кодировки в ID и унифицировал разнородные значения (изменил 'Y'/'N' на чёткие 'Yes'/'No').
* Оптимизация структуры: Удалил неиспользуемые в дальнейшем анализе столбцы, чтобы облегчить структуру таблицы и уменьшить размер базы данных.

### Стек технологий и навыки:
* СУБД: MySQL
* Использованные операторы и функции: ROW_NUMBER(), SUBSTRING, INSTR, CASE WHEN, STR_TO_DATE, SELF JOIN, CTE
